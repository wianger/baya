# Bundled typography

All TTF files are unmodified upstream static releases of Vercel's Geist
family under SIL OFL 1.1; the notices ship in the APK and are registered with
Flutter's LicenseRegistry.

| Role | Family |
| --- | --- |
| Interface and the wordmark | Geist (400, 500, 600, 700) |
| Code, commands, file paths | Geist Mono |

Upstream: https://github.com/vercel/geist-font. `sources.json` pins each file
to its commit and records SHA-256. Scripts Geist does not cover (Chinese
among them) use the phone's own fonts.
