# Bundled typography

All TTF files are unmodified upstream releases under SIL OFL 1.1; the
notices ship in the APK and are registered with Flutter's LicenseRegistry.

| Role | Family | Upstream |
| --- | --- | --- |
| Interface | Geist (400, 500, 600, 700) | https://github.com/vercel/geist-font |
| Code, commands, file paths | Geist Mono | https://github.com/vercel/geist-font |
| The Baya wordmark | Pinyon Script | https://github.com/google/fonts/tree/main/ofl/pinyonscript |

`sources.json` pins each file to its commit and records SHA-256. Scripts Geist does not cover (Chinese
among them) use the phone's own fonts.
