# Development

Baya has two parts:

- `host/`: the `baya` command and resident host (TypeScript, Node.js 24);
- `app/`: the Android app (Flutter).

`PROTOCOL.md` describes how they talk.

## Host

```sh
cd host
pnpm install --ignore-scripts
pnpm dev -- status     # runs src/cli.ts directly
pnpm lint              # Biome (pnpm format fixes)
pnpm typecheck         # src and tests
pnpm test              # Vitest
pnpm build             # dist/, for running from source
pnpm build:binary      # the single-file executable, build/bin/baya-<platform>-<arch>
```

The pnpm setup skips install scripts; the prebuilt keyring and esbuild
packages do not need them.

## App

```powershell
cd app
flutter pub get
flutter gen-l10n
flutter analyze
flutter test
```

`flutter test` includes an accessibility check of the main screens (48 × 48
touch areas, labels, WCAG AA contrast) in both themes. On a device or
emulator:

```powershell
flutter test integration_test
```

runs the real app; CI does this on an Android emulator for every push to
`main`.

Strings live in `lib/l10n/app_en.arb` and `app_zh.arb`. The brand artwork
(launcher icons, the in-app mark, the banner) is generated by
`python branding/generate.py`; see `branding/README.md`.

### Screenshots for review

```powershell
.\scripts\preview-app-windows.ps1 -Theme dark   # or light
```

renders the design gallery and a sample chat to
`%USERPROFILE%\Downloads\Baya-UI-Preview`.

### Release build

Release builds are signed with the release key, which lives outside the
checkout under `%LOCALAPPDATA%\RemotePiMobileBuild\signing` and is referenced
by `app/android/key.properties`. Its certificate:

```text
SHA-256 bdaba7b38a226cf6bcf2673d24a8f56453ffdce66f3b3402e48e0bca7b884eaa
```

```powershell
$env:HTTPS_PROXY = 'http://127.0.0.1:7897'   # when the network needs it
.\scripts\build-app-windows.ps1
```

builds the ARM64 release APK to `%USERPROFILE%\Downloads\Baya-Android.apk`
from a snapshot of the source and verifies its signature. Without the key,
build with `flutter build apk --debug`.

Check an APK:

```powershell
$tools = 'C:\Scoop\persist\android-clt\build-tools\36.0.0'
& "$tools\aapt2.exe" dump badging "$env:USERPROFILE\Downloads\Baya-Android.apk"
& "$tools\apksigner.bat" verify --print-certs "$env:USERPROFILE\Downloads\Baya-Android.apk"
```

Releasing is described in [releasing.md](releasing.md).
